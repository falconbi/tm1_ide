# TM1 IDE — video playlists

Six playlists. Each item below is one video of about 3 minutes.

## 1. Build with AI
- **MCP server** — an agent builds dimensions, cubes, rules and processes
- **AI inside change sets** — the agent's work is tracked and tested like anyone's
- **Built-in assistant** — views and subsets from a description

## 2. The developer's IDE
- **IDE overview** — the whole IDE in one tour
- **Rules and TI** — Rules Editor, TI Editor, TI Debugger
- **Model structure** — Dimension Editor, Alternate Hierarchies, Subset Editor, Cube Editor, Period Builder
- **Views and data** — View Editor, pivot drill-down, MDX Builder, cell formatting, SQL Editor
- **Understanding the model** — Cube Map, Rule Lens, Data sources, process summaries and runbooks
- **Tracing a number** — Cell Trace, Transaction Log, Used In, Cross-Object Search
- **Editing comfort** — autocomplete, Function Catalog, Naming Dictionary, Explorer, tabs and split panes, shortcuts

## 3. Deployment and Git
- **Change Sets**
- **Assertions**
- **Deploy through TM1 Git**
- **Deploy History** — including a mention of the earlier REST pipeline

## 4. Lenses
- **The Lens pages** — the Workforce model
- **Lens Editor**
- **The Lens App** — sign in, the home page, working in a Lens

## 5. Administration
- **Monitoring** — jobs and sessions
- **Server Admin** — configuration, metrics, maintenance mode, Save data
- **Logs** — transaction log, TI error logs, change history; message log and audit log *(to build)*
- **MCP** — read-only vs build mode, agent logins, masking, read audit
- **Lens App setup** — which TM1 server, sign-in, HTTPS for embedding in PAW
- **Chores and files**

## 6. Installation
- **Install the IDE**
- **Connect a server** — direct or through PAW, v11 or v12
