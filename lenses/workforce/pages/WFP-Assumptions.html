Assumptions

Assumptions

Finance's monthly rates by company: merit, promotion, inflation, vacancy, bonus pool, on-costs and the two indices.

Reading the grid

White = a value you set in that month. Grey italic = carried forward from the last white cell — it is not a new input. Type in a grey cell to set a new value from that month; type 0 to clear an input and fall back to the carry-forward.

Using it

Type 3 or 3% for 3%. A value applies from its month onward until the next input, so you set it once. Actuals Cutoff and Merit Review are months — pick them from the list. Pivot compares months or companies.

Who can change

WFP Finance; everyone can read.
